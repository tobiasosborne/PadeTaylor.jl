### [LOW] Observation — `_pIV_rhs` uses a `Rational` coefficient `(3//2)`

Location: `src/Painleve.jl:117`. The PIV RHS multiplies `(3//2) * u^3`
using a Julia `Rational{Int}`. This is *mathematically exact* and equals
the reference `3/2` coefficient (RF2014 md:45). It is not a bug. Noted
only because Rational-times-Complex/Arb promotion paths can occasionally
surprise; here `u^3` dominates the promotion and the result type is
correct. No sign/coefficient error. Confidence that this is benign: high.

## Areas verified correct

- **PI RHS** — `src/Painleve.jl:101` `(z,u,up) -> 6*u^2 + z`. Matches
  FW2011 md:48 `d²u/dz² = 6u² + z` exactly.

- **PII RHS** — `src/Painleve.jl:104` `(z,u,up) -> 2*u^3 + z*u + α`.
  Matches FW2014 md:47 `2u³ + zu + α` exactly (sign and parameter
  placement correct; `+α`, not `−α`).

- **PIV RHS** — `src/Painleve.jl:117-118`
  `up^2/(2*u) + (3//2)*u^3 + 4*z*u^2 + 2*(z^2-α)*u + β/u`. All five terms
  match RF2014 md:45 term-by-term: `(u')²/(2u)` ✓, `(3/2)u³` ✓, `4zu²` ✓,
  `2(z²−α)u` ✓ (the `−α` is inside the parenthesised coefficient, correct),
  `β/u` ✓. The `u = 0` fail-loud guard (lines 112-116) is correct per
  ADR-0006 Fail-loud and CLAUDE.md Rule 1.

- **PIII / PV / PVI parameter wiring** — `_build_transformed`
  (`src/Painleve.jl:241-258`) passes `(kw.α, kw.β, kw.γ, kw.δ)` in that
  order to the factory; the factory signatures
  (`CoordTransforms.jl:38,42`, `SheetTracker.jl:30,37`) take
  `(α, β, γ, δ)` in that order. No transposition. PVI `:transformed`
  reuses `pV_z_to_ζ`/`pV_ζ_to_z` — correct, because FFW2017 md:144 shows
  PVI's ζ-frame arises from the *same* `z = e^ζ` map as PV (only the RHS
  differs, supplied by `pVI_transformed_rhs`). PVI `:transformed_eta`
  routes through `pVI_z_to_η`/`pVI_η_to_z` per FFW2017 md:154 (`ζ = e^η`).
  (The internal algebra of the III/V/VI RHS closures lives in
  `CoordTransforms.jl`/`SheetTracker.jl` — a different agent's scope —
  but the wiring from the assigned files is correct.)

- **PI tritronquée IC** — `src/PainleveNamed.jl:101-102`
  `u0 = -0.1875543083404949`, `up0 = 0.3049055602612289`. Digit-for-digit

- **PII Hastings–McLeod IC** — `src/PainleveNamed.jl:141-143`. The
