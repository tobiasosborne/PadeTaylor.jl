## Findings

No bug found. Every equation, companion entry, Jacobian entry,
closed-form oracle, derivative formula, and branch choice in the two
files matches its cited ground truth term-by-term. Details of the
verification are recorded under "Areas verified correct".

The audit specifically chased the highest-suspicion intermittency
mechanism — the cube-root branch logic in `pI2_tritronquee_ic`
(`src/PainleveHierarchy.jl:557-566`) — and found the only `Y`
discontinuity sits on the positive real axis (`φ0 = 0`, `θ` jumps
`2π → 4π`), which is the **pole wedge** explicitly excluded from the V0
pole-free sector. Within the usable sector the map is continuous (the
two `φ0`-halves join continuously at `φ0 = π`, the sector centre). So
the branch logic does not manufacture a spurious discontinuity inside
the region where the seed is meant to be used.

## Areas verified correct

### `P_I^(2)` 4-vector companion RHS — correct
`src/PainleveHierarchy.jl:207-210`. KKG eq. (p12)
(`tritronquee_coeff.tex:128-133`) isolated for `u_xxxx` gives
`u_xxxx = -10 u_x^2 - 20 u u_xx - 40(u^3 - 6tu + 6x)`. With
`(y1,y2,y3,y4) = (u,u',u'',u''')` the code's last row
`-10*y2^2 - 20*y1*y3 - 40*(y1^3 - 6*t*y1 + 6*x)` matches every term
(`findings.md:86-91`). The trivial chain `[y2,y3,y4,…]` is the correct
companion lift.

### `m = 1` companion RHS + v0.1 anchor — correct
`src/PainleveHierarchy.jl:195` `[y2, 6*y1^2 + x]` equals v0.1
`_pI_rhs() = 6u^2 + z` (`src/Painleve.jl:101`); same normalisation, no
rescale (ADR-0022:142-149). Reduction/consistency anchor holds.

### Analytic companion Jacobian (m=1, m=2) — correct
`src/PainleveHierarchy.jl:300-323`. m=2 row-4 partials:
`∂/∂y1 = -20y3 - 120y1^2 + 240t`, `∂/∂y2 = -20y2`,
`∂/∂y3 = -20y1`, `∂/∂y4 = 0` — exactly the derivative of the verified
row-4 RHS. Super-diagonal identity rows are the correct chain Jacobian.
m=1 `∂/∂y1(6y1^2+x) = 12y1` correct.

### PII rational oracles `u_1, u_2, u_3` — correct

### PIV equation + entire oracles — correct
`src/PainleveClosedForm.jl:162-184`. The PIV form in the docstring

### `pI2_tritronquee_ic` leading-order components — correct
`src/PainleveHierarchy.jl:563-566`. With `Y = -∛6·x^{1/3}`,

### `pI2_tritronquee_ic` `n_terms=2` correction — correct
`src/PainleveHierarchy.jl:570-575,546-550`. At `t=0` only `c_6=1`

### Negative-real-axis legacy path == off-axis general path — correct
`src/PainleveHierarchy.jl:532-552`. On `x0 < 0` (`φ0 = π ⇒ θ = 3π`,
`exp(iθ/3) = -1`, `Y = +∛6·r^{1/3}`), the literal `r`-power expressions
`(+c r^{1/3}, -(1/3)c r^{-2/3}, -(2/9)c r^{-5/3}, -(10/27)c r^{-8/3})`
and the Δ-block `(+r^{-2},+2r^{-3},+6r^{-4},+24r^{-5})/36` reproduce the

`findings.md:282-309` (bead 0ln.31). Positive-branch-on-`x<0` is the
ODE-consistent root (`u³ = 6|x| > 0`).

### V0-sheet branch logic — correct (the prime intermittency suspect)
`src/PainleveHierarchy.jl:559-562`. `θ = φ0 ≤ 0 ? φ0+4π : φ0+2π` maps
the principal angle `φ0 ∈ (-π,π]` onto `θ ∈ (2π,4π]` with the negative
real axis at `θ = 3π`. The V0 pole-free sector
(`tex:229-231`, `θ ≈ [6.912, 11.937] ⊂ (2π,4π]`) is covered
continuously: the upper half (`φ0∈(0,π]→θ∈(2π,3π]`) and lower half
(`φ0∈(-π,0]→θ∈(3π,4π]`) join at `φ0 = π` (sector centre), continuous.
The only `2π` jump in `θ` (hence a `2π/3` rotation jump in `Y`) is at
`φ0 = 0`, the positive real axis = pole wedge, explicitly outside the
V0 sector. No spurious discontinuity inside the usable region.

### No in-place buffer aliasing / order dependence
All RHS / Jacobian closures
(`src/PainleveHierarchy.jl:195,207-210,307-308,319-322`) and the IC
builder return freshly-allocated literal arrays per call; the IC builder
mutates only its own local `y`. No shared mutable state, no RNG, no
order dependence — nothing that could intermittently corrupt a computed
solution from these two files.

### Fail-fast guards — consistent with Rule 1
Pole guards in `pii_rational` / `piv_entire`, the `abs(x0) ≥ 1` and
`n_terms ∈ {1,2}` / `t ≠ 0`-with-`n_terms=2` guards in
`pI2_tritronquee_ic`, and the `m ∈ {1,2}` / length checks in
`painleve_hierarchy*` all throw `ArgumentError` with suggestions; no
silent NaN/Inf path was found.
