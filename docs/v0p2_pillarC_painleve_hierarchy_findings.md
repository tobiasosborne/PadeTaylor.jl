## 1. Explicit P_I^{(2)} Equation

### KKG 2015 normalization (canonical for v0.2)

The second member of the PI hierarchy is the **fourth-order ODE**:

```
u_xxxx + 10 u_x^2 + 20 u u_xx + 40(u^3 - 6tu + 6x) = 0
```

with parameter `t ∈ C` entering the equation parametrically.

**Source:** KapaevKleinGrava2015_PI2_tritronquee_ConstrApprox41.pdf, page 1,
equation (1.1):

> "Equation P_I^2, the second member in the hierarchy of ODEs associated with
> the classical first Painlevé equation P_I, y_{xx} = 6y^2 + x, is the 4th
> order ODE   u_xxxx + 10 u_x^2 + 20 u u_{xx} + 40(u^3 − 6tu + 6x) = 0"

Note: the parameter is `t`; `x` is the independent variable. For the
tritronquée numerical study, KKG set `t = 0` in many computations (the
"single-slice" study), yielding:

```
u_xxxx + 10 u_x^2 + 20 u u_xx + 40(u^3 + 6x) = 0     [t = 0 slice]
```

### ClaeysGrava 2011 normalization

ClaeysGrava2011_KdV_painleve_CMP313.pdf, page 3, equation (1.17):

```
X = T U - [ (1/6) U^3 + (1/24)(U_X^2 + 2U U_XX) + (1/240) U_XXXX ]
```

This is the same equation rearranged as:
```
U_XXXX + 10 U_X^2 + 20 U U_XX + 40 U^3 - (40/6·6) ... 
```
The CG form uses variables `(X, T)` and the equation written as `X = T U - [...]`
is algebraically equivalent to KKG (1.1) after rescaling:
`X ↔ -x, T ↔ -6t, U ↔ u`. The pole-free real solution satisfies
`U(X,T) ≃ ∓(6|X|)^{1/3} ∓ (1/3) 6^{2/3} T |X|^{-1/3} + O(|X|^{-1})`
as `X → ±∞` for fixed `T ∈ R` (CG 2011 p. 3, eq. (1.18)).

### Cosgrove 2000 identification

Cosgrove2000_USyd_2000-6_higher_painleve_polynomial_classII.pdf, page 3,
equation (1.8) (F-V):

```
F-V:   y^(iv) = 20 y y'' + 10(y')^2 - 40 y^3 + α y + κx + β
```

This is precisely P_I^{(2)} in Cosgrove's notation. When `κ ≠ 0` (generic),
this is "the second member of the Painlevé-I hierarchy" (Cosgrove p. 3:
"Equation F-V is well known to be a group-invariant reduction of the KdV5
equation. When κ ≠ 0, it is the second member of the Painlevé-I hierarchy.").
The parameters `(α, κ, β)` in F-V map to KKG's `(t, x)` as follows:
`α = -240t`, `κ·x → 240x` (both sides of the KKG equation scaled by 40),
with `β = 0` for the generic tritronquée.

## 2. First-Order Vector Form

Using the **KKG 2015 normalization** with `u = y_1`, `u' = y_2`, `u'' = y_3`,
`u''' = y_4`, the equation becomes:

```
y_1' = y_2
y_2' = y_3
y_3' = y_4
y_4' = -10 y_2^2 - 20 y_1 y_3 - 40(y_1^3 - 6t y_1 + 6x)
```

where `x` is the independent variable, `t` is the parameter, and
`y = (y_1, y_2, y_3, y_4) ∈ C^4`.

This is the exact substrate for PadeTaylor v0.2's vector stepper:
`y'(x) = f(x, t; y)` with

```julia
function f_PI2(x, t, y)
    y1, y2, y3, y4 = y
    return [y2,
            y3,
            y4,
            -10*y2^2 - 20*y1*y3 - 40*(y1^3 - 6*t*y1 + 6*x)]
end
```

**Derivation:** from KKG 2015 p. 1, eq. (1.1), isolating `u_xxxx`:
`u_xxxx = -10 u_x^2 - 20 u u_xx - 40 u^3 + 240 t u - 240 x`.

## 3. The PI Hierarchy in General

### Lenard–Gelfand–Dikii recursion

The PI hierarchy is generated by the **Lenard recursion operator** acting on
the KdV Hamiltonians. The standard form appears in BaloghBertolaBothner2017,
p. 6, eq. (2.1):

```
(d/dx) L_{N+1}[u] = (d^3/dx^3 + 4u d/dx + 2u_x) L_N[u],   L_0[u] = 1/2
```

with integration constant fixed by `L_n[0] = 0` for `n ≥ 1`.

The first three Lenard operators:
```
L_1[u] = u
L_2[u] = u_xx + 3u^2
L_3[u] = u_xxxx + 5(u_x)^2 + 10u u_xx + 10u^3
```

**(BaloghBertolaBothner2017 p. 6, eq. (2.1) and surrounding text.)**

The **n-th member** of the PI hierarchy (KdV reduction) is the ODE of order 2n:

```
(d/dx + 2u) L_n[u_x - u^2] = xu + α_n
```

**(JoshiMazzocco2003 p. 2, eq. (6), written as `P_II^{(n)}`; the PI hierarchy
is obtained by a symmetry reduction. BaloghBertolaBothner2017 p. 6, eq. (1.10)
gives this directly for the PII hierarchy, with PI obtained by `α_n → ∞`-type
reduction.)**

More precisely, the PI hierarchy is the sequence of ODEs arising from
stationary reductions of the KdV hierarchy. The n-th member is an ODE of
order **2n** in the dependent variable. Explicitly:

- **n = 1:** PI, `u_xx = 6u^2 + x`. Order 2.
- **n = 2:** P_I^{(2)}, `u_xxxx + 10u_x^2 + 20uu_xx + 40u^3 = 6x + 6t·(constant terms)`. Order 4.
- **n = m:** order 2m.

**Source for the order-2m statement:** ClaeysGrava2011 p. 1 (the P_I^m equation
of order 2m is used throughout) and ClaeysGrava2011 p. 5 (ClaeysGrava2011
footnote/discussion of m=2 giving the 4th-order equation).

The **PI hierarchy** (distinct from the PII hierarchy) is generated by the
**Gelfand–Dikii** / **Lenard** recursion applied to the KdV hierarchy, taking
stationary solutions of the 2m-th KdV flow. This gives:

```
P_I^{(m)}:  order 2m,  m = 1, 2, 3, ...
```

Member m = 1 is PI itself. Member m = 2 is P_I^{(2)} (the 4th-order ODE above).

## 4. The P_I^{(2)} Tritronquée: Asymptotics, Sectors, and Initial Conditions

### Defining asymptotic condition

**KKG 2015 p. 27, eq. (7.1):**

```
u ~ -∛6 · x^{1/3}     as |x| → ∞
```

in certain sectors of the complex x-plane.

> **Branch note (bead `padetaylor-0ln.31`, 2026-05-21).** KKG write this
> asymptotic *uniformly*; the sign on the **real** axis depends entirely
> on which branch of `x^{1/3}` is taken. The decisive ground truth is
> the `P_I^(2)` ODE itself: the leading dominant balance `40(u³+6x)=0`
> (`t=0`) gives `u³ = -6x`. On the **negative real axis** (`x<0`),
> `u³ = 6|x| > 0`, so the **real root is POSITIVE**: `u = +∛6·|x|^{1/3}`.
> This *is* `-∛6·x^{1/3}` evaluated with the **real** cube root — for
> `x<0`, `x^{1/3} = -|x|^{1/3}`, so `-∛6·x^{1/3} = +∛6·|x|^{1/3} > 0`.
> Seeding the *negative* value `-∛6·|x|^{1/3}` on `x<0` is **not a
> `P_I^(2)` solution at all** — its ODE residual is `≈ -480·|x|`
> (`-9600` at `x=-20`). The "Practical IC" block §4 below has been
> corrected; see the corrected component list there.

More precisely, the leading asymptotic is:

```
u_f(x,t) = Σ_{n=0}^∞ a_n x^{-(1/3)(n-1)},   a_0 = -∛6
```

**(KKG 2015 p. 24, eq. (5.15) and (5.16), the formal asymptotic series for the
tritronquée at `t = 0`: `b_0 = -∛6`, `b_1 = 1/36`, with further `b_n` from the
recurrence.)**

The series (7.2) in KKG p. 27 gives:

```
u = Y + Σ_{n=1}^∞ c_n Y^{-n},   Y = -∛6 · x^{1/3}
```

with `c_1 = 2t`, `c_2 = c_3 = c_4 = 0`, `c_5 = -(8/3)t^3`, `c_6 = 1`,
`c_7 = (16/3)t^4`, `c_8 = -(10/3)t`, `c_9 = 0`, ... (all listed explicitly

## 5. Cosgrove Classification: Polynomial Class, F-I through F-XVIII

### Complete list of polynomial-class fourth-order Painlevé equations

Cosgrove's paper (Cosgrove2000) completes the Painlevé classification of
fourth-order ODEs in the polynomial class. The full list is F-I through
F-XVIII (18 equations), building on Bureau symbols P1 and P2.

**Bureau symbol P2 equations** (from Cosgrove Paper I, referenced in
Cosgrove2000 p. 2, and stated in Cosgrove2000 p. 2, eqs. (1.4)-(1.9)):

| Label | Equation |
|-------|----------|
| F-I | `y^(iv) = 12yy'' + 12(y')^2 + (αx+β)y' + 2αy - (1/6)(αx+β)^2` |
| F-II | `y^(iv) = 3yy'' - 4(y')^2` (Bureau barrier equation, non-Painlevé) |
| F-III | `y^(iv) = 15yy'' + (45/4)(y')^2 - 15y^3 + αy + β` |
| F-IV | `y^(iv) = 30yy'' - 60y^3 + αy + β` |
| F-V | `y^(iv) = 20yy'' + 10(y')^2 - 40y^3 + αy + κx + β` |
| F-VI | `y^(iv) = 18yy'' + 9(y')^2 - 24y^3 + αy^2 + (1/9)α^2 y + κx + β` |

**Bureau symbol P1 equations** (Cosgrove2000 p. 4-6, new results, eqs.
(1.13)-(1.24)):
F-VII through F-XVIII (12 equations, including F-VIII, F-IX, ..., F-XVIII).

### F-V is P_I^{(2)}

Cosgrove2000 p. 3, below eq. (1.9):

> "Equation F-V is well known to be a group-invariant reduction of the KdV5
> equation. When κ ≠ 0, it is the second member of the Painlevé-I hierarchy."

**F-V** with `κ ≠ 0`:
```
y^(iv) = 20 y y'' + 10(y')^2 - 40 y^3 + α y + κx + β
```

Setting `α = -240t`, `κ = 240`, `β = 0` and rescaling `y ↦ u`, `x ↦ x`
recovers KKG eq. (1.1):
```
u_xxxx + 10u_x^2 + 20uu_xx + 40u^3 - 240tu + 240x = 0
= u_xxxx + 10u_x^2 + 20uu_xx + 40(u^3 - 6tu + 6x) = 0   ✓
```

When `κ = 0`, F-V specializes to a hyperelliptic-function solvable case
(Cosgrove p. 3: "When κ = 0, its solution in terms of hyperelliptic functions
was given by Drach [13].").

## 6. Pole-Free / Smooth Members: Claeys 2010 and 2011

### Claeys 2011 (pole-free PI hierarchy)

Claeys2011_pole_free_PI_hierarchy_1107.0214.pdf, pages 1-3 (Theorem 1.1):

For every m ≥ 1 (even), the m-th member P_I^m of the PI hierarchy possesses:

1. **Formal series solutions** `q_{f,∞}` and `q_{f,0}` as `s → ±∞`
   (Claeys2011 Theorem 1.1, p. 2, eqs. (8)-(9), citing sectors `S_n`).
2. **True solutions** that are pole-free on the real line in these sectors
   (Theorem 1.1, part 2).
3. For m **even**: real pole-free solutions exist (Claeys2011 p. 2, intro:
   "the first conjecture about the existence of real pole-free solutions to
   the P_I^m equations for even m was posed in random matrix theory").
4. The pole-free sectors have angular width `2nπ/(2n+1)` (m = n in
   Claeys2011 notation; width of sectors S_n, Theorem 1.1 p. 3).
5. Tritronquée-type solutions (unique in sectors of width `4nπ/(2n+1)`) exist
   for all n ≥ 1.

**For P_I^{(2)} specifically (n = 2 in Claeys2011, which uses index m=2):**
- Pole-free sectors of angular width `4π/5`.
- Unique tritronquée in sectors of angular width `8π/5`.
- Solutions with asymptotics `V_{f,∞} = ((-1)^2 x / (2c_2))^{1/4} × Σ ...`
  (Claeys2011 eq. (8)).

### Claeys 2010 (asymptotics for P_I^{(2)})

Claeys2010_PI2_asymptotics_JPhysA43.pdf, abstract and p. 1-8:

This paper proves existence and describes asymptotics of the "special solution"
(pole-free on the real axis) to P_I^{(2)}, which is the `U_0(x,t)` of KKG.

Key result: For `t = 0`, the unique real solution with `u ~ ∓(6|x|)^{1/3}` as
`x → ±∞` has **no poles for real x**. (Claeys2010, abstract and Theorem 1.1.)

This real solution is what KKG call Type II (`U_0`). It is smooth for all
real `x` and `t ∈ R`.

**Sanity-check implication for PadeTaylor:** When integrating along the
**real axis** with `t ∈ R`, no pole-bridging steps should be needed — the Type
II solution is globally smooth there. Pole-bridging (the core of PadeTaylor)
is needed when exploring **complex x** (as KKG do in Figures 7.4–7.12).

`t = 0`. Using the **real, ODE-consistent** branch `Y = +∛6 · |x_0|^{1/3}`

```
c_2 = 0
c_5 = -(8/3)t^3 = 0
```
